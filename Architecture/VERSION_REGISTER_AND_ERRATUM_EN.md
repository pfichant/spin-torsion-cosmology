## 1. Conventions

- **Two numbering schemes.** The title page and running head show the **public number** of the Zenodo deposit ("Preprint v8"). The **internal number** (revision of the source file) appears only in each document's version notes.
- **Status labels.** `CALIBRATED`: value fitted to data, not a prediction. `CALCULATED-CONDITIONAL`: calculation conditional on a stated assumption. `HISTORICAL`: value from an earlier version, kept for traceability, not active. `OPEN`: unresolved question. `WITHDRAWN`: statement retracted.
- **This register creates no result.** It only records differences between versions. In case of discrepancy, the text of the new version prevails.

## 4. Corrections explicitly signalled

These corrections concern **data or figures** of the online versions. They are signalled here rather than corrected silently, in line with the author's decision of 22/09/2026.

1. **Foundation II, void-statistics figure** (`Fig_Void_Statistics`). In v4 the points labelled "Observations (SDSS BOSS Catalog)" were **simulated** (analytic curve plus noise, fixed seed), and the "Fit Statistics" box (χ²_ν = 1.14 / 4.82) was hard-coded in the script. The figure is replaced; no simulated data are presented as observations.
2. **Foundation II, NGC 6503.** v4 used a data file (`Data_S1_NGC6503_ECF.csv`, 24 points) that does not match the SPARC file (31 points). The refit on the actual SPARC data gives χ²_ν = **1.68** (not 0.97). The rotation curve (Fig. 26) is redone on SPARC.
3. **Foundation II, NGC 6503 MCMC figure** (Fig. 32). The online figure was drawn from a **synthetic normal distribution** (hard-coded mean and covariance) and displayed ± 0.22 / ± 0.20 / V∞ = 114.0 ± 3.5. It is now drawn from the actual MCMC chain (`mcmc_ngc6503_sparc.py`, made deterministic): log10 ρ0 = −23.252 (+0.040 / −0.039) g cm⁻³, R_s = 1.705 (+0.089 / −0.087) kpc, V∞ = 113.96 (+0.80 / −0.77) km/s, correlation −0.997, χ²_ν = 1.68. The values ± 0.22 / ± 0.20 / ± 3.5 did not come from sampling the likelihood.
4. **Foundation III — Cosmological Physics, Israel repulsion.** v2 contained, in two illustrative places, a **dimensionally incorrect** form of the Israel repulsion. It is corrected.
5. **Mahalanobis distance 2.22σ / 7.32σ** (six deposited documents). These values came from a 13-observable DESI block, now withdrawn: see § 3.2.
6. **BOSS error at z = 0.61.** The online versions used the statistical error alone: see § 3.2.
